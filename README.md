## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/GirthSymbol.git`
2. `cd GirthSymbol`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure GirthSymbol, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
